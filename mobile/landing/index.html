Six layers of navigation truth

Every layer governs the ones below it. None can lie silently — the layer above is watching.

🧭

Raw Multi-GNSS PVT

Weighted least squares on GPS, GLONASS, Galileo, BeiDou, QZSS, NavIC, SBAS. 15-state EKF. χ² RAIM integrity.

🛡

Never Fails

5-tier routing fallback. 5-provider tile rotation. IMU-only dead reckoning when GPS dies.

🤖

Explainable AI Copilot

Every routing decision explained in natural language. Q&A on position trust, route slowness, signal safety.

🔐

Differential Privacy

Laplace noise ε=1.0 on all shared data. Raw GPS never leaves device. GDPR export in one click.

🚨

Emergency System

G-force crash detection (3 severity tiers). SOS beacon persists through signal loss.

📡

Spoof Detection

Detects GNSS jumps, CN0 floors, single-constellation anomalies. Forces degraded mode automatically.

🎯

Self-Correcting

Every prediction measured against reality. ETA calibration learns from actual arrival times. No silent bias.

⚖

Self-Governing

Blocks unsafe actions. Refuses to reroute when self-confidence drops. Honest about its own limits.

💾

100% Offline

Service Worker caches 5000 tiles. Graph routing. Local state continuity.
